# Правила работы с 1С:Напарником - Управление_нашей_фирмой_демонстрационная_база.СогласованиеЗаказов

## Формы
При создании и доработке форм (документов, справочников, обработок) обязательно загружай навык `razrabotka-form` («Разработка форм») и следуй ему — это единая концепция UI проекта.

## Версионирование объектов
При создании любого нового документа конфигурации обязательно подключай штатный механизм БСП «Версионирование объектов». Собственный механизм истории изменений не разрабатывай.
